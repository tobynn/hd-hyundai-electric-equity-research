# [HD현대일렉트릭 공시 자동 갱신]

## [자동으로 기록하는 항목]

GitHub Actions는 평일 한국시간 오전 8시 20분에 DART를 조회한다. 사업보고서, 반기보고서, 분기보고서, 영업잠정실적 공시 가운데 새로 접수된 항목을 찾는다.

새 공시가 있으면 `data/disclosure_watch.json`과 `report/DISCLOSURE_UPDATE_LOG.md`에 접수번호와 DART 원문 링크를 기록한다.

## [자동으로 바꾸지 않는 항목]

공시 감지는 실제치, 전망, 투자의견, 목표주가를 자동으로 수정하지 않는다. 전력기기는 수주 시점, 납기, 계약 통화, 원재료, 지역별 마진의 영향이 크다. 다음 항목을 원문과 회사 IR 자료로 확인한 뒤 모델을 수정한다.

- 수주액과 수주잔고의 제품·지역·납기 구성
- 전력변압기·GIS·배전기기·신사업의 매출과 이익률
- 청주 배전캠퍼스의 CAPEX 집행과 양산 시점
- 계약자산, 매출채권, 재고, 선수금
- 북미와 중동 수주의 가격과 계약 조건
- 현금·금융자산·리스부채·주식 수
- 지배주주 자본과 비지배지분

## [GitHub Secret 설정]

저장소 Settings → Secrets and variables → Actions에서 `DART_API_KEY`를 추가한다. OpenDART에서 발급받은 인증키를 값으로 저장하면 다음 예약 실행부터 자동 조회가 시작된다.
