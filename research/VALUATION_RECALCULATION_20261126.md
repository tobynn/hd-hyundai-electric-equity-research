# [2026.11.26 잔존가치 재계산]

이 문서는 2026.11.24 기준주가와 기존 2027~2031년 현금흐름 가정을 유지한 계산 실험이다. 신규 목표주가 또는 투자의견이 아니다. 회사 발표와 분석자의 가정을 구분한다. 기존 Excel과 Python 모델은 아래 수정식을 아직 반영하지 않았으므로 기존 값은 과거 버전으로 취급한다.

## [기존 오류]

기존 스크립트는 잔존가치를 `2031년 FCFF × (1+g)/(WACC-g)`로 계산했다. ROIC 14%를 설명 자료에 제시했으나 해당 식에는 사용하지 않았다. 따라서 14%가 기존 결과를 만든 입력값이라는 설명은 잘못이다.

## [수정식과 연결]

단위 십억원, 주당 원. 성숙기에 성장률 g와 신규 투자 ROIC가 유지되며 성장에 필요한 재투자율을 `g/ROIC`로 계산한다고 가정한다. 이는 분석자의 가정이다.

| 입력 및 계산 | 값 |
| --- | ---: |
| 2031년 매출 전망 | 6,627.0 |
| 2031년 영업이익률 | 22.0% |
| EBIT | 1,457.94 |
| 세율 가정 | 24.0% |
| 세후영업이익(NOPAT) | 1,108.0344 |
| 영구성장률 g | 2.2% |
| 성숙기 신규 투자 ROIC | 14.0% |
| 성숙기 재투자율 g/ROIC | 15.71% |
| WACC | 9.0% |
| 명시기간 FCFF 현재가치 | 2,963.68 |
| 잔존가치 현재가치 | 9,122.56 |
| 순현금 가정 | +648.574 |
| 비지배지분 | -4.028 |
| 지배주주 가치 | 12,730.79 |
| 경제적 주식 수 가정 | 35.99백만 주 |
| 주당가치 | 약 353,731원 |

`2032년 FCFF = 2031년 NOPAT × (1+g) × (1-g/ROIC)`

`잔존가치 현재가치 = 2032년 FCFF ÷ (WACC-g) ÷ (1+WACC)^5`

명시기간 FCFF는 기존 스크립트의 2027~2031년 값이다. 이 접근은 매출·마진·CAPEX·운전자본과 성숙기 재투자 가정이 정당하다는 증거가 아니다. 2031년 잔여 영업자산과 정상 CAPEX의 적정성을 별도로 검증해야 한다. 기존 WACC, 주식 수, 순현금의 기준일도 다시 대조해야 한다.

## [할인율과 성장률 민감도]

단위 원. 각 칸에서 2027~2031년 FCFF, 순현금, 주식 수와 ROIC 14%는 그대로 유지하고 할인율만 각 열의 모든 현금흐름에 적용한다. 성장률은 잔존기간에만 적용한다.

| WACC / g | 1.5% | 2.2% | 3.0% |
| --- | ---: | ---: | ---: |
| 8.0% | 394,772 | 413,827 | 441,779 |
| 9.0% | 342,039 | 353,731 | 370,148 |
| 10.0% | 301,794 | 309,094 | 318,989 |

PER 14.2배와 정상화 EPS 25,000원의 근거, RIM의 기초 자본과 현금·배당 및 성숙기 재투자 경로, 3분기 보고서의 계정별 가치 연결을 계속 확인해야 한다. 민감도 표만으로 투자의견을 정할 수 없다.
